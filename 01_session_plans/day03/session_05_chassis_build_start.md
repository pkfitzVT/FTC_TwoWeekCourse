## Background / Mini-Lesson

Use the Team Strategy Guide, Robot Behavior Specification, Demo Robot Design Analysis notes, Subsystem Design Cycle guide, and structure/function reading to ask what scoring plan and robot behaviors the frame/drivetrain subsystem must support. Then use the chassis physics and space planning reading to frame size constraints, load support, turning, clearance, attachment space, and repair access. Pair it with a brief tool, fastener, alignment, and parts-management mini-lesson.

## Student-Led Discussion

Prompt: Which design choice should we protect when the build gets difficult or slow?

Readiness rule: Before finalizing a chassis design, each team must review Demo Robot Design Analysis notes and identify at least one design feature to borrow, one design feature to modify or avoid, and one question or test before building.

Use the Chassis Design Choice SLD to break the decision into mini-rounds for chassis needs, frame shape, material/connectors, motor/wheel placement, electronics/battery placement, reserved mechanism space, and first build/test plan.

## Team Task

Teams use the Chassis Design Choice SLD to review their copied Team Strategy Guide and Robot Behavior Specification, use Demo Robot Design Analysis evidence, start a frame/drivetrain subsystem cycle entry, confirm what scoring strategy and behaviors the chassis supports, identify one feature to borrow, one feature to modify or avoid, and one question or test before building, then review chassis decisions and assign immediate build roles.

## Build / Program / Test Time
