# Day 7, Session 13: Trigger Implementation and First Shots

## Purpose

Mount the trigger on the robot and attempt controlled one-ball shots.

## Learning Target

Students can test whether the trigger releases one ball at a time and use observations to choose the next adjustment.

## Success Criteria

- Trigger moves freely before flywheel testing.
- Teams test one ball at a time.
- Teams record shot observations before making changes.

## Teacher Preparation

Prepare test station, target area, balls, safety boundaries, programming devices, batteries, and shot observation logs.

## Student-Led Discussion / Decision

Prompt: What pattern did our team notice after several controlled shots?

## Work Time Options

- Assembly: mount or refine trigger.
- Programming: adjust load/release values.
- Testing: controlled one-ball shots.
- Documentation: observation log.

## Must / Should / Could

- **Must:** Test trigger motion safely before launching.
- **Should:** Attempt controlled one-ball shots and record observations.
- **Could:** Compare one variable such as angle, power, compression, or trigger timing.

## Deliverables

- Mounted trigger photo.
- Shot observation log.
- Code or position notes.
- Engineering portfolio entry.

## Engineering Portfolio Evidence

Teams should add trigger positions, observed shot pattern, change made, result, and next adjustment.

## Reflection / Share-Out

- What changed when the trigger was mounted on the robot instead of tested by hand?

## Teacher Notes

Keep teams from rapid-fire testing before they can feed one ball safely. Require one-change-at-a-time debugging.
