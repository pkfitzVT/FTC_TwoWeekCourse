# Robotics Course Sessions

This folder contains teacher-facing session pages for the robotics course.

The main course overview is located at:

`../teacher_facing_robotics_course_overview.md`

## Files

- `pre_course_meet_the_teacher_robotics_intro.md`: optional 25-minute pre-course introduction. This does not replace Day 1 Session 1.
- `day_01_session_01_first_ftc_safety_trust_goals.md` through `day_10_session_20_final_demonstrations_and_reflection.md`: the 20 official course session pages.

Each official session file follows a common structure:

- Purpose
- Learning Target
- Success Criteria
- Teacher Preparation
- Student Background Reading / Preparation
- Student-Led Discussion / Decision
- Work Time Options
- Must / Should / Could
- Deliverables
- Engineering Portfolio Evidence
- Reflection / Share-Out
- Teacher Notes
- Linked Resources

These files are intended to become website pages or printable teacher-facing lesson documents.
