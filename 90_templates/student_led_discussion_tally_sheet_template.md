# Student-Led Discussion Tally Sheet Template

Use this sheet during short 5-10 minute student-led discussions about engineering design decisions.

The goal is not to talk the most. The goal is to help the team make a better engineering decision.

## Discussion Codes

| Code | What to Tally |
|---|---|
| Q | A student asks a clarifying or useful question. |
| C | A student makes a claim, suggestion, or design idea. |
| E | A student supports an idea with evidence. |
| B | A student builds on, agrees with, or strengthens another person's idea. |
| O | A student raises a reasonable objection or concern. |
| D | A student helps summarize, compare options, decide, or name the next test. |
| X | A student makes an off-task or unsupported comment. |

## 5-10 Minute Discussion Flow

| Time | Move |
|---|---|
| 1 minute | State the design decision and options. |
| 2 minutes | Share claims and evidence. |
| 2 minutes | Ask clarifying questions and raise objections. |
| 2 minutes | Compare options and connect to strategy/behavior plan. |
| 1-3 minutes | Make a decision, record evidence, and name the next test. |

## App-Facing Note

This student sheet is the simple live version for in-person tallying.

The app-facing scoring taxonomy may use more detailed categories and subcategories, such as evidence from readings, game strategy, robot behavior plans, test data, build/driving experience, safety concerns, strategy concerns, decision synthesis, or next-test recommendations.

The live student sheet should stay simple:

```text
Q, C, E, B, O, D, X
```
