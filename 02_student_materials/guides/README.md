# Student Guides

This folder contains reusable student-facing guides and classroom routines for the robotics course.

These files are not tied to only one session. They support habits students should use across build, programming, testing, documentation, and revision work.

## Guides

- [`what_should_i_be_doing_right_now_robotics_work_ahead_menu.md`](what_should_i_be_doing_right_now_robotics_work_ahead_menu.md): productive work-ahead menu for students who are not directly building at that moment.
- [`robotics_design_build_revise_process_handout.md`](robotics_design_build_revise_process_handout.md): design/build/revise process guide for moving from rough concept to buildable robot decisions.
- [`subsystem_design_cycle_guide.md`](subsystem_design_cycle_guide.md): guide for designing, programming, testing, documenting, and integrating robot subsystems one at a time.
- [`subsystem_design_operation_testing_cycle_guide.md`](subsystem_design_operation_testing_cycle_guide.md): course-level guide connecting game goals, robot behavior targets, Design SLDs, operations roles, integrated tests, postmortems, tuning, acceptable performance ranges, and documentation.
