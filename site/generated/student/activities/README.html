Student Activities

Student-facing activities guide hands-on work, data collection, testing, and competition-style challenges.

Activities generate evidence. SLDs use that evidence to make decisions. Guides and readings explain concepts. Decision menus help teams compare design options.

Current Activities

Activity Purpose Related Reading / Guide Related SLD
Demo Robot Design Analysis and Observation Activity Inspect, operate, sketch, photograph, and compare working robot designs. Demo-robot materials, design menus, and How This Robotics Course Works Chassis, strategy, and subsystem design SLDs
Controller Mapping Drive Comparison Compare D-pad and joystick driving with evidence from safe chassis trials. Controller mapping background and OnBot Java examples Controller Mapping SLD

Drive Reliability Round-Robin Test chassis, controls, and human operation under shared-field conditions. Drive-control materials and controller mapping background Robot Operations Role Plan SLD and Performance Testing Postmortem SLD

Future Activity Folder Pattern

Use predictable filenames when adding new activity folders:

activity_guide.md
data_sheet.md
comparison_or_reflection_sheet.md
manual_printable.pdf

Not every activity needs all four files. Use only the files that help students do the activity, collect evidence, or prepare for the related SLD.
