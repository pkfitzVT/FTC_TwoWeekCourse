Course Content Inventory

This inventory maps the current Markdown and PDF files in the repository after the course-map, website-session, student-guide, and impact-study planning updates. It is organizational only.

Status meanings:

  • keep: useful course material or organizing document.
  • source candidate: likely editable Markdown source for future course materials.
  • generated export: likely PDF generated from Markdown.
  • duplicate candidate: overlaps strongly with another file and needs a source-of-truth decision.
  • utility: support file rather than core course content.
  • archive candidate: likely not part of the course-content source set.
